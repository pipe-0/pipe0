Figuring out how to connect an MCP server to Grok Bot can be daunting.
You may navigate to the plugins section or your remote cursor account.

Neither place is correct.

The correct way to connect an MCP sever to Grok Bot is to paste the URL into its chat 
and let Grok handle the rest.

## Example

Let's say you want to connect the [pipe0](https://pipe0.com) MCP server. Simply 
go into any bot chat and say:

```txt
Can you connect this MCP server: https://api.pipe0.com/v1/mcp
```

The bot works out the rest. It checks the connector catalog, finds nothing,
and decides to add the URL as a custom remote MCP. It also reads the server's
auth setup to set up the connection correctly.

![Grok Bot's System chat showing a confirmation card titled "Add the pipe0 connector?" with the remote URL and Add pipe0 and Cancel buttons](/media/blog/20260921-1.png)

After you've followed the instructions, your server should be connected.
Follow up in the same chat to be sure.
