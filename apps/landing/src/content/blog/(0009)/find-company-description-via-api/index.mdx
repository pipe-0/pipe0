In this blog post, we explore how you can generate a company description via an API endpoint.
For this, we use [pipe0](https://pipe0.com).

Pipe0 is a framework for data enrichment. To enrich data with pipe0 you use enrichment pipes.
There are several pipes available to generate a company description via API. For this blog post, we're 
using the pipe [company:overview@3](https://www.pipe0.com/docs/pipe-catalog/company:overview/3).

Besides the description, this pipe returns the company's industry, headcount, founding year, and estimated revenue.

It costs 1 credit per company.

## Prerequisites

🙆🏼‍♂️ Go to [pipe0](https://pipe0.com) and create an account <br />
🔑 Create an API Key

## Request object

```typescript tab="Typescript"
const id = "1";
const result = await fetch("https://api.pipe0.com/v1/pipes/run/sync", {
  method: "POST",
  headers: {
    "Authorization": `Bearer <API_KEY>`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    pipes: [{ pipe_id: "company:overview@3" }],
    input: [{ id, company_domain: "<COMPANY_DOMAIN>" }]
  })
});

const response = await result.json();

// Print description
console.log(response.records[id].fields.company_description.value);
```

```shell tab="cURL"
curl -X POST "https://api.pipe0.com/v1/pipes/run/sync" \
-H "Authorization: Bearer API_KEY" \
-H "Content-Type: application/json" \
-d '{
    "pipes": [{ "pipe_id": "company:overview@3" }],
    "input": [{ "id": "1", "company_domain": "<COMPANY_DOMAIN>" }]
}'
```
