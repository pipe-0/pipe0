## Enrichment in one sentence, then the map

- Define without ceremony: you have a record (a signup, a lead, a
  company) and enrichment adds the fields you are missing (email,
  phone, size, funding, tech stack). One sentence, then the map.
- Name the trust problem this post answers, once: seven of the
  eight articles ranking for this query are published by a vendor
  in the list, and each ranks itself first without disclosure. We
  build pipe0, it appears in one category below with the same
  disclosure sentence we always use, and every price here was
  checked against the vendor's live page in August 2026.
- The taxonomy, eight categories defined by what each optimizes
  for: databases (own one dataset), workbenches (orchestrate many
  providers in a UI), waterfall specialists (contact coverage via
  cascading), single-source APIs (one job, developer-priced), raw
  data vendors (bulk rows for data teams), verification (keep what
  you have sendable), visitor identification (turn traffic into
  records), meta providers (many providers behind one API, sheet,
  and MCP server).
- Two sentences on why categories exist: no vendor can own the
  best data, the best orchestration, and the best developer
  access simultaneously; each category is a bet on which layer
  matters. Categories fail differently, which is what the gotchas
  below encode.

## One verified pick per category

- Databases: ZoomInfo for US enterprise depth (org charts, direct
  dials, intent). Real cost: median contract $33,500/yr across
  1,569 tracked purchases, 3-seat minimum, 60-day renewal notice.
  Gotcha: the renewal record (BBB complaints, reported 10-20%
  uplifts). Budget pick: Apollo at $49-99/user/mo; gotcha:
  fair-use caps and plan-gated API depth. Deep dives:
  clay-vs-zoominfo, uplead-vs-zoominfo, leadiq-vs-zoominfo.
- Workbench: Clay, the category's ecosystem leader since 2017, and
  as of July 2026 it ships a public API, CLI, and MCP on all
  plans, so the old "no API" knock is dead; retire it. Gotcha,
  current: the March 2026 two-currency repricing ($185/mo floor,
  Data Credits plus Actions, 30% top-up premium, no sandbox, and
  a learning curve practitioners measure in weeks). Deep dives:
  fullenrich-vs-clay, clay-alternatives-for-agencies, and the
  existing clay-alternatives post.
- Waterfall specialist: FullEnrich; the cleanest published rate
  card in the category ($0.055 per found email, $0.55 per found
  mobile at Pro, unlimited seats). Gotcha: "verified or it's
  free" bills catch-alls as found, and their own docs rate
  unresolved catch-alls up to ~40% bounce risk. Deep dive:
  fullenrich-vs-clay.
- Single-source APIs: People Data Labs for scale ($0.28/person
  record, bills on match only); Hunter for simplicity (free 50
  credits/mo and a genuine pay-as-you-go calculator, $0.05 down
  to $0.0056 per credit). Gotcha for the class: one dataset means
  one hit rate; published live tests cluster 49-72%. Deep dives:
  icypeas-api-guide, prospeo-api-guide, best-sdr-apis.
- Raw data: Coresignal, credited for publishing real prices
  ($49-$5,000/mo tiers) in a quote-only category. Gotcha: bulk
  rows are not answers; the license terms that matter are not on
  the website. Deep dive: coresignal-alternatives.
- Verification: ZeroBounce for the deepest status taxonomy and
  first-party quality-score data; gotcha: at list price it runs
  4-7x MillionVerifier at equal volume ($649 vs $149 per 100k),
  so volume buyers should quote both. Both are true pay-per-use
  with non-expiring credits. Deep dive: zerobounce-status-codes.
- Visitor identification: RB2B for US person-level (free tier,
  150 resolutions/mo, company-level); Dealfront for EU
  company-level. Gotcha for the class: reverse-IP match rates run
  30-60% and no vendor escapes the physics; person-level is
  US-only for legal reasons, not roadmap ones. Deep dives:
  rb2b-alternatives, zoominfo-websights-alternatives.
- [pipe0 →] Meta provider: pipe0, with the disclosure. What earns
  the pick: Clay-like sheets (2M rows, point-in-time recovery),
  a first-class API, and an MCP server on one engine; curated
  waterfalls across 50+ providers billed only on success; from
  $49/mo, 20 free credits, BYO keys on any plan; 3-10x more cost
  efficient than traditional tabular tools. Gotcha, honestly:
  a younger ecosystem than Clay's, and no proprietary dataset,
  so ZoomInfo-style org charts and intent are not here. Deep
  dive: /compare/pipe0-vs-clay.

## Which category are you actually shopping in

- Three sorting questions, one paragraph each. Volume: hundreds
  (any UI works), tens of thousands (unit economics dominate;
  read the cost guide), millions (raw data or meta API).
  Interface: humans in a UI, code against an API, or agents over
  MCP. Data need: contact info, firmographics, signals, or
  hygiene; most stacks need two, which is why the categories
  compose.
- The common mis-buy, named from the research: paying workbench
  prices when the need was a waterfall (orchestration you never
  use), or entering a $25k database contract for one bundled
  feature (the WebSights pattern). Link both posts.

## How the categories stack, and who the buyer is becoming

- Three reference stacks, one line each: SMB manual (Apollo +
  MillionVerifier); ops-heavy (workbench or pipe0 sheets +
  verification + CRM sync); agent-native (discovery + waterfall +
  validation behind one MCP server, agent decides scope; link
  claude-code-sales-prospecting and the waterfall-MCP post).
- Close on the shift with the stat, not a summary: 13 of the 18
  vendors checked in this research now ship an official MCP
  server, and the ranking listicles mention it approximately
  never. The buyer of enrichment is becoming an agent; the
  categories that price and package for that buyer first are the
  ones this page will be rewritten around next year.
