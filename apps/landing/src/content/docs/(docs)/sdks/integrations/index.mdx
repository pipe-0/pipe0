Integrations bring pipe0 into the tools you already build with. Pick the framework or app your agent runs in, and it gets
pipe0 search and enrichment as tools, behind one API key.

## Agent frameworks

These packages give agents you build in code a small set of tools: find people, enrich a person, enrich a company.
