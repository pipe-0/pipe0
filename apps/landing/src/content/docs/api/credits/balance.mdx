Get the credits your organization has left. The API key tells pipe0 which organization you mean, so the request takes no parameters. A production run is refused before it starts when its estimated cost meets or exceeds this balance. Sandbox runs don't use credits.

`balance` is the total you can spend. `purchased_balance` is the part of it you bought as one-off credit purchases. Plan credits are spent first.
