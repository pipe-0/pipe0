## What is Exa?

Exa is a search engine built for AI applications. Its API searches the
web, returns page contents, answers questions, and runs research agents.
For sales and marketing teams the relevant part is the Agent API: describe
a list in plain language, define the columns, and it searches, checks and
returns structured rows.

## Can Exa build lead lists?

Yes, lists of a few hundred rows. An Agent run returned 146 to 341 local
businesses per city in our tests, and the rows were accurate. It beat
Parallel's research tasks on every list. Purpose-built data beat it on
volume: DataForSEO's business listings returned two to six times as many
local businesses, in seconds.

A run can return far more when the list already exists in one public
source. Asked for New York City barbershops, Exa found the state licence
registry and returned 1,932 rows, 1,715 of them licensed shops. Registry
rows carry legal entity names ("CUTTING POINT CORP") and rarely a phone
number: 8% had one, against 80% in DataForSEO's list.

## How long does an Exa Agent run take, and what does it cost?

An ultra run takes three to six minutes and costs about $1 to $1.50; a
medium run takes about two minutes for a flat $0.10. Both are slower than
a database query and faster than Parallel's research tasks, which took
eight to fourteen minutes. Ultra's time limit can't be set below five
minutes, so it doesn't suit a step that must answer quickly.

<ListBenchmark chart="time" highlight="exa" />

Because you pay per run, the cost per row depends on how many rows the run
finds: $0.46 to $1.23 per 1,000 rows for medium and $0.76 to $7.53 for
ultra, against $0.37 for DataForSEO.

## When does a database filter beat Exa?

Whenever a filter can describe the list. Online-only brands look like
Exa's territory, since they have no storefront to find on a map. But a
company database with a technology filter found three times as many
verified Shopify brands in seconds, and already held 25 of the 26 Exa
found.

<ListBenchmark chart="shopify" />

The same holds for local businesses with a clear category. Use Exa for
what a filter can't express, then check whether the database had it first.

## Can Exa get every exhibitor or member from a public list?

No. It returns an accurate sample of a few hundred, not the whole list. On
a trade show whose 3,194 exhibitors are public on one page, Exa returned
212, and 96% of them were real. A research agent that can read the
directory page directly returned the full list, but only when it found
that page; a typical run returned fewer rows than Exa.

<ListBenchmark chart="exhibitors" />

So Exa is the dependable choice when a few hundred correct rows are
enough. When you need every entry, point a scraper or a list-reading agent
at the directory page. We haven't yet tested lists that no single page
holds, such as companies mentioned across many news articles.

## Can Exa's search return local businesses?

Yes, 10 at a time. Exa's search returns places with address, phone,
rating and opening hours, and they were precise: 591 of 602 NYC
barbershops were inside the city. Each call returns at most 10 places, so
a city-wide list means splitting the city into ZIP codes yourself. Across
178 NYC ZIP codes that gave 602 unique barbershops in 20 seconds for
$1.25, about 15% of what DataForSEO returned.

## Exa and pipe0

pipe0 offers Exa's ultra agent as a list-building search, with a $5
spending cap and a 10-minute limit per run, billed from Exa's own reported
cost. Its agent sends local businesses to DataForSEO and filterable
companies to the company databases, and uses Exa for briefs no filter can
express.

## Exa, DataForSEO or Parallel: which should you use?

Use DataForSEO for local businesses by category, a company database for
anything a filter can describe, and Parallel for researching rows you
already have. Use Exa when the list needs a prose brief and a few hundred
accurate rows are enough.
